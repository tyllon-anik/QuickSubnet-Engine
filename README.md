# 🟢 QuickSubnet Engine

**An advanced, terminal-themed IPv4 Subnet Calculator and Network Analyzer for Android.**

QuickSubnet Engine is a professional-grade networking utility designed for cybersecurity enthusiasts, network administrators, and IT students. Built with a sleek hacker/terminal aesthetic, it performs complex IP calculations locally using fast bitwise operations.

## 🚀 Key Features

*   **Subnet Calculation:** Instantly calculate Network ID, Broadcast ID, and Wildcard Mask.
*   **IP Class & Type Detection:** Automatically identifies IP Class (A, B, C, D, E) and Type (Public, Private, Loopback, APIPA).
*   **Binary Analysis:** Real-time translation of IP addresses and Subnet Masks into raw binary format for deep packet-level understanding.
*   **Host Range Analyzer:** Displays Total Range, Usable Range, and the exact number of usable hosts.
*   **Cybersecurity UI:** A sleek, dark terminal-style interface with glowing neon-green accents.

## 🛠️ Tech Stack

*   **Platform:** Android (Java)
*   **Core Logic:** Low-level bitwise operations and shifting for zero-latency calculations.
*   **Architecture:** Native Android SDK with custom UI components.

## 📱 Download & Install

You can download the latest production-ready APK from the **Releases** section on the right side of this repository.

1. Download `QuickSubnet_Engine.apk`.
2. Allow "Install from unknown sources" on your Android device.
3. Install and run the engine.
